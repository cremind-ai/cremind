Tracking more accounts

Claude only reveals an account's usage to a session signed in to it. Give each extra account its own Claude Code profile — a separate config folder with its own login — and it is tracked alongside your main one without ever changing which account your sessions use.

  1. Ask Cremind to add a Claude account profile, e.g. “add a Claude usage profile named spare1”. A window opens with Claude Code in the new profile.
  2. Sign in there with the account to track, type /usage, then /exit.
  3. To refresh it later, press Open below and run /usage again. Idle accounts stay accurate on their own — usage only grows when an account is used.

      How the figures are measured

      Official readings come from Claude Code itself: its own usage cache (refreshed when you sign in or run /usage), the terminal status line after each reply, and limit-reached notices.

      Between readings — and for VS Code sessions, which never run a status line — the monitor adds up what each reply cost at API list prices, from the session transcripts, and converts it with a calibration: … Figures built this way are marked ≈. Each new official reading replaces the estimate and refines the calibration.
