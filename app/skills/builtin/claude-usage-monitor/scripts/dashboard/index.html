    Tracking more accounts

    Anthropic reveals an account's usage only to that account's login. Give each extra account its own Claude Code profile — a separate config folder with its own login — and it is tracked alongside the one your Claude Code uses. A switch signs nothing out: the chosen account's login moves into your Claude Code, and the one it replaces moves to a profile of its own, so every account stays signed in here.

    1. Ask Cremind to add a Claude account, e.g. “add a Claude account named spare1”. A window opens with Claude Code in the new profile.
    2. Sign in there with that account, then /exit. Its official figures appear within seconds, and it joins Your Claude Code uses above: one click switches to it.
    3. That's all: the monitor keeps every login renewed while it is idle. Only if an account shows “sign in again”, press Open below and run /login. Switch with the button rather than /login in VS Code: /login drops the account it replaces from this computer.

        How the figures are measured

        Official figures from Anthropic — the same as claude.ai's Settings → Usage, including usage on claude.ai, the apps and other computers. The monitor asks Anthropic's usage API with each profile's Claude login, as Claude Code's /usage does.

        Claude Code's own readings count too: its usage cache, the terminal status line after each reply, and limit-reached notices.

        Estimates fill in only when no recent official figure is at hand (live figures off, a profile without a usable login, no network): the monitor adds up what each reply cost at API list prices, from the session transcripts, and converts it with a calibration: … Figures built this way are marked ≈.

        Each profile's Claude login is sent only to Anthropic, to ask for its usage (and renew it when it expired, as Claude Code does); it is never copied, logged or shown — a switch moves it between Claude Code's own folders on this computer. Conversation content is never read.
